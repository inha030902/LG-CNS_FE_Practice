### 코드 — 비교용 React Router (`lgcns-fe/`, 같은 커밋)
```tsx
// main.tsx
<BrowserRouter>
  <App />
</BrowserRouter>

// App.tsx
<nav className="site-nav">
  <NavLink to="/">Home</NavLink>
  <NavLink to="/about">About</NavLink>
  <NavLink to="/login">Login</NavLink>
</nav>

  <Route path="/" element={<Home />} />
  <Route path="/about" element={<About />} />
  <Route path="/login" element={<Login />} />
</Routes>
```

### 🆚 React Router와 Next.js App Router 비교
| | React (`react-router-dom`) | Next.js (App Router) |
|---|---|---|
| 라우트 정의 | 코드에 `<Route path=...>`로 직접 적음 | 폴더 구조가 곧 주소 (`app/login/page.tsx` → `/login`) |
| 링크 | `<NavLink to="/">` | `<Link href="/">` (`next/link`) |
| 공통 레이아웃 | `App`에 nav를 두고 아래에 `<Routes>` | `layout.tsx`가 `children`으로 페이지를 감쌈 |
| 설치 | 따로 설치 (`npm i react-router-dom`) | 기본 내장 |

### 🔍 보충할 것
- **세션 / 쿠키 / 토큰 정의** (필기에 "공부"라고 적어 둠)
  - 쿠키: 브라우저에 저장되고 요청마다 자동으로 같이 보내지는 작은 데이터
  - 세션: 로그인 정보를 **서버**에 저장하고, 브라우저에는 세션 ID만 쿠키로 줌
  - 토큰(JWT): 로그인 정보를 서명한 문자열을 **클라이언트**가 들고 다님. 서버는 서명만 확인 (서버에 저장 안 함)
- JWT vs 세션 장단점: 확장성(서버 여러 대), 강제 로그아웃, 탈취 시 위험, 저장 위치(localStorage vs httpOnly 쿠키)
- Next.js 미들웨어가 하는 일: 페이지에 도착하기 전에 요청을 가로챔 → 로그인 안 했으면 `/login`으로 보내기 같은 처리 (Next 16에서는 이름이 `proxy`로 바뀌었는지 공식 문서에서 확인하기)
- `next/image`의 `Image`가 `<img>`보다 나은 점: 자동 최적화, lazy loading, 크기 지정으로 레이아웃 밀림 방지
- `next/link`의 `Link`가 `<a>`와 다른 점: 페이지 전체를 새로 불러오지 않고 클라이언트에서 이동, 프리페치

### 코드 — twMerge로 기본값 덮어쓰기 (`atoms/CustomTitle.tsx`, `14:53`)
```tsx
import { twMerge } from "tailwind-merge";

export default function CustomTitle(
    {TitleType, className, children}
    :
    {TitleType: "h1" | "h2" | "h3" | "h4" | "h5" | "h6", className?: string | undefined, children: React.ReactNode}){
    return (
        <TitleType className={twMerge("text-2xl font-bold text-center text-white", className)}>
            {children}
        </TitleType>
    );
}
```
- `className="text-red-500"`을 넘기면 결과: `text-2xl font-bold text-center text-red-500`
  - 겹치는 것(글자색)만 넘겨받은 값으로 바뀌고, 나머지(크기·굵기·정렬)는 기본값 유지
- 그냥 문자열을 이어 붙이면(`` `text-white ${className}` ``) 안 되는 이유: Tailwind는 **클래스를 적은 순서가 아니라 CSS 파일 안의 순서**로 우선순위가 정해져서, 흰색이 남을 수 있음
- `TitleType`에 태그 이름을 받아서 `<TitleType>`으로 그림 → 하나의 컴포넌트로 h1~h6를 다 만듦

### 코드 — 반응형 네비게이션 (`15:46 fix: nav`, `15:48 fix: nav mobile`)
```tsx
// organisms/GlobaNavigation.tsx
<nav>
    <MobileNavigation />
    <DesktopNavigation />
</nav>

// molecules/DesktopNavigation.tsx: md(768px) 이상에서만 보임
<ul className="items-center gap-4 hidden md:flex ">
    <li><Link href="/">Home</Link></li>
    <li><Link href="/about">About</Link></li>
    <li><Link href="/contact">Contact</Link></li>
</ul>
```
```tsx
// molecules/MobileNavigation.tsx: md 미만에서만 보임
"use client";
import Link from "next/link"
import { useState } from "react";

export default function MobileNavigation(){
    const [isOpen, setIsOpen] = useState(false);
    return (
        <>
        <div className="md:hidden">
            <button onClick={() => setIsOpen(!isOpen)}>
                <span className="sr-only">Open main menu</span>
                <svg className="w-6 h-6" aria-hidden="true" ...>{/* 햄버거 아이콘 */}</svg>
            </button>
        </div>
        {isOpen && (
            <div className="md:hidden">
                <ul>
                    <li><Link href="/">Home</Link></li>
                </ul>
            </div>
        )}
        </>
    );
}
```

### 핵심 포인트
- **`"use client"`**: App Router 컴포넌트는 기본이 **서버 컴포넌트**. `useState`처럼 브라우저에서 상태가 필요하면 파일 맨 위에 `"use client"`를 붙여야 함
  - 오늘 코드에서 `"use client"`는 `MobileNavigation` 하나뿐. 상태가 필요한 파일만 클라이언트로 만드는 게 원칙
- **Tailwind 반응형은 모바일 우선**: 접두사 없는 클래스 = 모든 화면, `md:` = 768px 이상
  - `hidden md:flex` → 작은 화면에선 숨김, 큰 화면에서 보임
  - `md:hidden` → 큰 화면에선 숨김
  - 어제 필기 "모바일 우선, Tailwind도 이렇게 함"과 연결
- **`sr-only`**: 화면에선 안 보이지만 스크린리더는 읽음 → 아이콘만 있는 버튼에 이름 붙이기 (어제 "button vs div" 접근성 얘기와 연결)
- `{isOpen && (...)}`: 조건이 true일 때만 그리는 조건부 렌더링

### 🔍 보충할 것
- 서버 컴포넌트와 클라이언트 컴포넌트의 차이, 어제 Vite React(전부 클라이언트)와 비교
- `"use client"` 파일이 import하는 컴포넌트도 클라이언트가 됨 (경계가 따라 내려감)
- `/about`, `/contact` 링크는 있지만 아직 `page.tsx`가 없음 → 누르면 404
- 파일 이름 `GlobaNavigation.tsx`는 오타(`Global`)지만 컴포넌트 이름은 `GlobalNavigation`
